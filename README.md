## About Consulting Hub

Consulting Hub is a knowledge base built as a static site, organized to help consulting teams collect and revisit practical guidance in one place. It focuses on making reference material easy to scan, link, and reuse without requiring a build step.

The site works well for shared internal documentation, playbooks, and structured reference content. With cross-linked content types and curated source material, it supports faster lookup and a more navigable view of best practices, frameworks, and toolkit assets.

## Features

- Cross-linked content types for easier navigation between related entries
- Reference guides for common consulting topics and workflows
- Framework library to organize repeatable methods and patterns
- Toolkit resources for practical day-to-day use
- Source library for centralizing supporting material
- Static pages with no build step required
- Knowledge base structure suited to consulting teams
- Simple web delivery for broad access in browser-based environments

## Usage

Use Consulting Hub as a reference destination for internal consulting material, best practices, and supporting assets.

Typical workflow:

1. Open the site in a browser.
2. Browse the reference guides or framework library.
3. Follow cross-links between related topics.
4. Add or update content files as your consulting material evolves.
5. Re-deploy the static files when changes are ready.

For teams, the main value comes from keeping related knowledge organized in a shared, easy-to-navigate format.

## Configuration

Configuration is handled through the static site structure and content files rather than through a build pipeline.

Common places to manage content include:

- HTML pages for core sections
- linked resource files for reference material
- navigation entries and internal links in the site layout

If you extend the hub, keep naming and linking consistent so cross-references remain easy to follow.

## FAQ

**How do I update the content?**  
Edit the relevant static pages and linked resources, then publish the updated files again.

**Can this run locally?**  
Yes. Since it is a static website, you can open it locally or serve it from a simple web server.

**Where do settings live?**  
Most structure and organization live in the page files and linked content. If you add navigation or shared layout elements, keep those in the site root or shared includes you use.

**What if links break?**  
Check cross-linked pages and file paths first, then verify that all referenced resources were moved or renamed together.
